## 命令行数据库恢复

使用独立 `/tmp/thought-final.sqlite` 运行生产浏览器测试后执行：

```bash
DATABASE_PATH=/tmp/thought-final.sqlite npm run db:backup -- /tmp/thought-final-backup.sqlite
# 新增一个测试账号，确认备份用户数3、当前测试库4
# 停止实际服务进程后
DATABASE_PATH=/tmp/thought-final.sqlite npm run db:restore -- /tmp/thought-final-backup.sqlite
```

恢复后与备份的14张表逐行比较完全一致；`PRAGMA integrity_check`为ok，`PRAGMA foreign_key_check`没有违规记录。旧库已保留为恢复前备份。没有对用户正式数据执行破坏性验证。
