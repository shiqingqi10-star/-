## 衣服案例怎样推进

无 AI 流程须由用户在「更多→调整引导」选择「考虑一次购买」，规则不对自由文本做假理解。自动化验收输入“我在思考今天买不买这件衣服”，依次记录“想更亮眼、更快乐”和“舞会”。下一问进入**近期是否有确定的使用机会**，不继续索取想象画面。

- 明确有安排：核对适用性→可接受的支出→带条件的当前倾向。
- 暂时没有安排：询问愿意为拥有它付出的代价，再谈支出与倾向；不预设“没用途就不该买”。
- 不确定：保留原话及未知，允许先看成果或选择继续确认，不补出安排或强制形成行动。
- 自由表达仍可直接提交，基础规则只按明确选项分支，不声称已识别其含义。

单元测试覆盖上述分支，浏览器覆盖选择+补充、暂停刷新、换问法保留、后续选项清空、比较选择及修改理解。AI 提示词和输入契约使用离线测试提供方验证，不能据此声称真实 DeepSeek 每次都能正确推进。

## Windows ZIP 更新

1. 在旧服务终端按 Ctrl+C 停止服务。确认没有另一终端同时运行此工程，尤其不要对同一 data 同时开两份应用。
2. 备份整个旧工程，至少保留自己的 `.env`、存在时的 `.env.local`、完整 `data` 文件夹（以及配置的其他 DATABASE_PATH）。不要删除 SQLite 的 -wal/-shm 文件。
3. 下载 **work 分支**的 `thought-organizer-focus-2026-10-16-r5.zip`，解压到新目录；打开其中含 package.json 的 `thought-organizer` 文件夹。包内不附密钥；将原有后端环境配置和完整数据放回相同相对位置，不用模板覆盖它们。
4. 使用 Node.js 24 或以上，在该文件夹地址栏输入 `cmd`，依次执行：

   ```bat
   npm ci
   npm run build
   npm run start
   ```

5. 看到服务 Ready 后打开 `http://localhost:3000`。如修改了端口，应同步保留正确的 APP_ORIGIN。登录页或设置必须显示 **思考空间 · 2026.10.16-r5**。首页写问题、开始梳理，第二页默认应只有当前问题/回答和少量线索；历史在「前面的回答」，日志在「更多→AI运行记录」。

无需清空 data 或重新注册。旧内容可直接继续。首次运行会沿用既有增量初始化；启动报错时保留终端原错误，不删除数据库或重装数据。界面标记不一致时核对解压目录、RELEASE.json、正在运行的终端目录及本次构建结果；本轮不能替你检查 Windows 本地实际目录。
