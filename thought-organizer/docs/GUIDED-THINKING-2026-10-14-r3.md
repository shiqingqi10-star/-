## 现有功能入口

- 原文旁展开后可“编辑原文”“原文历史”。
- 成果里的未知可“留下待确认问题”，下一步可创建普通行动或在编辑器选择验证任务；判断旁可补充依据和记录判断变化。
- 正式记录可以打开详情；卡片仍可补充依据、留下疑问和关联下一步。
- “看看它们怎么连接”打开原有完整逻辑图。关系、多前提、支持/反对和连接理由仍在高级整理中编辑。
- “更多操作：梳理”里的“高级编辑与完整整理”进入旧工作区，保留全部卡片、关系、证据、验证、复盘、拆分合并、批量选择及历史AI分析预览/采纳/反馈。高级整理可“返回当前追问”，不是新手必经流程。
- 导出与个人备份入口到设置；“待想清楚”和“下一步”仍是跨思考的完整列表。设置与回收站在侧栏底部，手机通过导航按钮进入。

## Windows ZIP用户更新

1. 在旧服务终端按Ctrl+C停止服务。先备份整个旧工程，至少保留原来的`.env`和完整`data`目录。如有多个终端同时启动，先正常停止重复服务；不要删除数据库、-wal/-shm来排锁。
2. 从GitHub的**work分支**取得`thought-organizer/releases/thought-organizer-guided-2026-10-14-r3.zip`，在文件页选择Download raw file。也可下载work分支Code→Download ZIP。main和旧r2 ZIP不是本轮版本。
3. 解压到一个新的目录，把备份的`.env`及完整`data`复制到新工程根目录（有package.json的目录）。包内没有真实.env和运行数据库。不要覆盖原.env。保持DATABASE_PATH指向原数据库，注意绝对路径配置是否需要调整。
4. 使用Node.js 24或以上，在新目录的PowerShell运行：

```powershell
node --version
npm ci
npm run typecheck
npm run check
npm test
npm run build
npm run start
```

5. 浏览器打开`http://localhost:3000`。登录页底部或设置顶部应显示**追问梳理 · 2026.10.14-r3**。首页主标题应是“有什么问题，你想理清楚？”，点击“开始梳理”后是一个追问。版本不符时，先核对终端所在目录、下载分支和当前运行进程，再判断构建问题。

数据库升级是增量执行，第一次访问自动创建新表，保留原有账号、密码、原文和全部整理数据。迁移后的数据库版本为2；不要用旧r2代码打开已升级数据库。需要回退时，在停服状态使用升级前的完整备份；不要用旧库覆盖新库而丢失新记录。

## 参考方法与实现边界

已读取[grilling Skill原文](https://github.com/mattpocock/skills/blob/main/skills/productivity/grilling/SKILL.md)，借鉴“前置条件影响后续问题、回答改变下一问、用户确认决定”的方法。未复制其代码或原文，也未安装Skill。原方法要求一轮展示多个问题和推荐答案、穷尽分支；这里遵循本产品要求，改为温和的单问、自由回答、随时暂停。

基础引导按已记录方向和用户主动选择分支工作，不声称理解自由文本、发现矛盾或智能归纳。未提交回答是草稿；只有提交的回答进入问答及AI输入。查看成果只准备候选，确认保存才写入正式业务记录。未知与跳过不会被视为问题已解决。
