## Windows ZIP更新

1. 在旧服务终端按Ctrl+C停止；另存备份完整工程，尤其 `.env`、存在时的 `.env.local`、整个 `data`。不要删除数据库的附属文件。
2. 下载 `work` 分支的 `releases/thought-organizer-outcomes-2026-10-16-r6.zip`，解压到新目录。ZIP包含一个 `thought-organizer` 顶层目录。
3. 将旧目录的环境文件和完整 `data` 复制到新工程同名位置，保留原有数据库路径和密钥配置。不要用 `.env.example` 覆盖原配置。密钥仅在后端，源码包不携带已部署密钥。
4. 安装Node.js 24或以上，在新工程含package.json的目录打开终端，执行：

```powershell
npm ci
npm run build
npm run start
```

5. 在电脑浏览器访问 `http://localhost:3000`；登录页底部或设置顶部应显示 **整理成果 · 2026.10.16-r6**。若没有，核对终端所在目录及实际监听3000端口的进程，不先归因于浏览器缓存。
