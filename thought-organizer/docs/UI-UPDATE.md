# 思路整理器界面优化与验证

日期：2026-10-12。本次直接修改既有工程，保留数据模型、业务接口与P0功能，不重建项目或清空数据库。

## 设计和主要变化

参考已下载的[Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill)中简报理解、重设计审查、层级、间距、一致性和可访问性方法。该技能主要面向宣传页，本工程是长期使用的产品工具，因此按用户明确要求采用浅色靛蓝界面、系统字体、原生CSS与现有Tailwind；不引入宣传横幅、装饰图片或动画。设计取值为DESIGN_VARIANCE=3、MOTION_INTENSITY=1、VISUAL_DENSITY=3。

- 首页：快速记录、真实更新时间排序的最近三个未归档主题、去重且最多五项今日关注。关注完整列表可访问问题、卡片等所有类型；收集箱改为简短入口。
- 导航：五个主要入口，顶部全局搜索，底部账号、设置、回收站和退出。手机通过导航抽屉访问。
- 主题：名称、目标与当前重点优先，其他资料展开查看。五个主标签覆盖原来的九种内容，仍将原kind保存在lastPosition中，旧位置无需数据迁移。
- 列表：主题摘要卡片、紧凑问题/任务/事件行、内容优先的思路卡片、摘要与日期优先的证据/复盘。点击进入完整详情；低频操作位于更多菜单。
- 编辑：基础信息和命名明确的补充区域，必填与等待信息状态字段可定位。只改可见字段时仍保留隐藏字段；类型切换不丢弃旧值。关联选择为标题搜索、结果选择与已选标签。
- AI：按需打开右侧面板，手机全宽抽屉，分析前展示与后端相同的实际范围。总结、疑点、下一步和卡片/关系分组；预览、幂等采纳、过期保护保持。无密钥时显示AI尚未配置，不调用外部模型。
- 设置和历史：自然日/月调用数来自真实数据库，分别说明原有滚动24小时/30天额度；历史显示可读字段，JSON只在高级查看中提供。
- 可访问性：原生dialog负责焦点约束和Escape关闭，打开表单聚焦第一项、关闭后返回触发控件；更多菜单支持方向键和Escape。逻辑图支持键盘打开完整卡片与关系，图形单独滚动。

## 主要文件

- components/Workspace.tsx：导航、首页、五个标签、各操作与状态组织。
- components/Editor.tsx、ReferencePicker.tsx：分层表单、关联搜索和草稿/冲突保留。
- components/EntityList.tsx、EntityDetail.tsx：按对象类型展示、完整详情及记录信息。
- components/AIAssistant.tsx、Settings.tsx：AI抽屉、分组结果、设置与可读用量。
- components/ui/Modal.tsx、Menu.tsx：对话框与键盘菜单。
- components/Graph.tsx、app/globals.css：逻辑图、统一色彩/尺寸变量及响应式布局。
- lib/presentation.ts：旧位置映射、真实更新时间和关注排序、字段布局。
- lib/auth.ts、app/api/[...path]/route.ts：仅为用量展示增加自然日/月及滚动计数，保持原接口字段和额度语义。

lib/schema.ts、数据库结构、认证与用户归属校验、AI密钥读取方式均未改动。唯一新增运行依赖为固定版本@radix-ui/react-icons 1.3.2，没有进行现有依赖的大版本升级。
