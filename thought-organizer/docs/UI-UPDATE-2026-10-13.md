# 思考空间更新与验收

日期：2026-10-13（Asia/Shanghai）。设置页的界面版本为 **思考空间 · 2026.10.13**。本轮在已有思路整理器源码上修改，保留账号、数据隔离、业务对象、原文历史、逻辑关系和全部既定P0入口。

## 本轮修改

- 首页只有“有什么事情，你想理清楚？”、多行正文及“保存，开始整理 / 先存着”。保存原文时保留空格与换行，只用第一句生成可修改的简称。主动作确认保存后进入整理，次动作留在记录页；不自动调用AI。
- 导航为我的思考、待想清楚、下一步。全部思考与未整理在我的思考中；问题支持状态和优先级，行动与事件支持今日、本周、逾期、全部及今日关注。搜索、设置、账号、回收站和个人备份入口保留。
- 主题与独立原文共用写下来、理清楚、往前走。全部旧kind映射到三个阶段，仍用原kind保存位置；独立记录不需要先建立主题。本地位置按账号保存，阶段同时保存在服务器。
- 卡片展示易懂的类型含义、核实状态及AI来源。点开正文可编辑；卡片可补充依据、留下疑问或安排下一步；问题可创建关联行动。有关依据在卡片详情中就近显示。
- 表单以正文或必要字段开始，其他字段折叠。验证任务的目标、具体行动、观察方式、判断条件等展开显示。标题搜索与已选标签保留多选；隐藏字段和切换类型不会清空数据。草稿按账号及独立思考区分，错误可定位，版本冲突保留输入。
- 按需打开思考变化，展示原文的最早留存版本、当前观点、依据、未知、判断、行动与验证记录。没有的部分中性提示，声明无法完整还原未留存过程。已有历史可展开；不生成分数、排名、虚构进度或总结。
- 保存后的轻提示依据实际动作产生。AI采纳只说明建议已确认保存，保留AI来源；个人推断仍待核实，完成行动不改变假设结论。
- AI默认收起，三个动作使用通俗文案；显示实际范围与完整字段，优先展示五条建议，其余可展开。理由与长内容可展开，保留预览、反馈、幂等与过期保护。无钥匙显示未配置并禁用调用。
- 保存接口成功而列表刷新失败时仍正确确认写入，并明确提示刷新失败，避免把成功写入误报为失败或重复创建。

## 数据兼容与必要后端补充

数据库表结构、迁移脚本、schemaVersion=1、会话、密钥读取和原有接口语义保持。没有修改.env、.env.local、正式数据库或已有运行数据，也未升级依赖。

原文仅增加可选refs和lastPosition字段，复用原有引用、归属校验、版本和历史模型。旧原文无需补字段。新增的thoughts/:id/items接口将创建和关联保存放入同一事务；冲突或失败回滚。编辑保留未变更的已删除旧引用，仍显示失效提示，新引用继续严格校验。

独立分析必须明确选择ids，不能默认发送全部未整理内容。独立思考通过明确引用（含反向来源）限定范围，不混入其他账号或无关记录。选中一条卡片时，只加入其必要来源和语义引用，不因原文的归属列表扩散到全部未选卡片。采纳时可以原子关联回原文；连续采纳的新增关联不误使分析过期，正文变化仍使分析过期。AI卡片来源由后端保持为AI推断。

## 取得及运行

完整源码位于现有GitHub仓库work分支，ZIP另存为releases/thought-organizer-thinking-space-2026-10-13.zip，并有相邻SHA256校验文件。ZIP包含完整源码、锁文件、数据库结构、初始化与重启验证脚本、测试、README、配置模板和截图；不包含真实环境文件、数据库、依赖或缓存，也不嵌套旧工程ZIP。

拉取前保留自己的代码改动。停止旧服务，保留.env、.env.local与data，在仓库根目录执行：

```bash
git switch work
git pull --ff-only origin work
cd thought-organizer
npm ci
npm run build
npm run start
```

开发使用npm run dev。无需重新初始化已有数据库或重新注册账号。浏览器刷新后，到设置查看“界面版本：思考空间 · 2026.10.13”。源码版本与生产构建需要同步更新，直接启动旧构建不会显示新界面。
